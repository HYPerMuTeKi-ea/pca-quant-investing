# Results

I included a compact snapshot of my completed run in the CSV files. The PNG files are the two key figures used in the written summary:

- `rolling_realised_volatility_63d.png` — 63-day annualised realised volatility.
- `cumulative_wealth.png` — cumulative wealth of one unit before transaction costs.

I can regenerate the tables and figures with `python scripts/run_backtest.py` after creating `data/processed/returns.csv`. These results describe this particular sample and set of assumptions; they are not evidence of a universal optimum.
